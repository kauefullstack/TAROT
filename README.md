# TAROT

Aplicação web de tarot construída com **React**, **TypeScript** e **Vite**, com estilização em Tailwind CSS e suporte a internacionalização.

## Stack

| Área | Tecnologia |
| --- | --- |
| Interface | React |
| Linguagem | TypeScript |
| Build e desenvolvimento | Vite |
| Estilos | Tailwind CSS |
| Navegação | React Router |
| Internacionalização | i18next |

## Começar

**Pré-requisitos:** Node.js e npm instalados.

```bash
git clone https://github.com/kauefullstack/TAROT.git
cd TAROT
npm install
npm run dev
```

O Vite informará no terminal o endereço local para abrir a aplicação.

## Build de produção

```bash
npm run build
```
