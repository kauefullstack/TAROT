# TAROT

Aplicação web de tarot desenvolvida com React, TypeScript e Vite.

## Tecnologias

- React e React Router
- TypeScript
- Vite e Tailwind CSS
- i18next para internacionalização

## Executar localmente

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```

As instruções de publicação na Hostinger estão em [README_UPLOAD.md](README_UPLOAD.md).
